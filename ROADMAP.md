# Breachpoint roadmap

Player feedback, in the order it's planned. Pre-alpha: order and scope can change.

## Up next (from player feedback, by urgency)

| # | Feature | Notes |
|---|---|---|
| 1 | Camo challenges | Unlock weapon camos by kills / headshots per gun. Needs per-player stats saved on the account server. |
| 2 | Leaderboard | Top players by wins / kills. Built on the same stats as camos. |
| 3 | Combat record (K/D, wins, accuracy) | Lifetime stats in the Friends / Profile panel. |
| 4 | More weapons and attachments | New primaries (LMG, marksman rifle, second SMG), more optics and barrels. |
| 5 | Level system | XP per match, ranks, unlocks. |
| 6 | Easier Create a Class | Visual attachment picker on the gun model instead of dropdowns. |

## Also requested
